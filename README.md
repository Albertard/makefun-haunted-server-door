# Funniest Sign on a Haunted Server Room Door

Entry for the [make.fun bounty](https://make.fun/bounty/u-eager-stork-81-9647-funniest-sign-on-a-haunted-ab1d019a) — one funny line for the door of a haunted server room, at most 120 characters.

## The entry

> WARNING: Haunted by the ghost of the last sysadmin. He still has not documented anything. Neither have you.

**107 characters** (gate: 1–120 characters, single line, not only white space).

## Why this line wins

A warning sign has to read like a warning sign, and this one does — "WARNING:" up front, posted on a door. The joke is the collision the judge brief asks for, office IT life against the supernatural: the ghost is not rattling chains, he is doing the most sysadmin thing imaginable, leaving nothing documented. Then the twist turns the sign on the reader — "Neither have you" — so the person standing at the door is suddenly part of the haunting.

## How to run

Node 22, standard library only — no dependencies, no network.

```sh
MAKEFUN_OUTPUT_DIR=/output node main.ts
```

This writes the entry to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`), after validating it against the competition gate: single line, 1–120 characters, no leading or trailing white space.
